# LOG-C2-031 — Designated Shipper (特定荷主) Logistics Compliance Specialist Q&A Agent

> **Category**: Cat 2 (domain workflow (a job to be done))
> **Industry**: Logistics

## Overview

Question-answering about the designated-shipper (特定荷主) obligations under Japan's logistics efficiency law. Given a question such as "Do we qualify as a designated shipper? Our annual freight volume is 12,000,000 ton-km", the agent classifies the obligation type (eligibility, threshold, obligation, deadline, general), retrieves matching entries from a curated knowledge base, computes the threshold test deterministically when a ton-km figure is supplied, and returns an answer in which every claim ends with a citation marker, together with the obligation type and the threshold verdict. No LLM step is involved. A question with no matching entry gets an explicit out-of-scope answer, an uncited answer is blocked, and every answer carries a disclaimer that it is not legal advice. The knowledge base shipped here is a small sample of six entries citing the 2024 amendment of the law and ministry guidance — replace it with your own reference set.

This is an agent template built with the **AGENTIC STAR** development platform and the
**AgentCore Framework**. It is intended to be taken as a starting point: fork it, adapt it to
your own data and policies, and run it inside your own AGENTIC STAR deployment.

## Requirements

**This template does not run standalone.** It requires:

| Requirement | Notes |
|---|---|
| **AGENTIC STAR platform** | The agent connects to the platform at start-up. Without it, start-up fails immediately (see *Behaviour without the platform* below). Deployment guides and API documentation: [AGENTIC STAR Developers](https://developers.fd.agenticstar.tm.softbank.jp/) |
| **AgentCore Framework** (`agenticstar-agentcore`) | Installed from PyPI as a dependency. |
| Python | 3.11 or later (`requires-python = ">=3.11"`) |

```bash
pip install -e .
```

### Behaviour without the platform

The framework is designed to run **only** on AGENTIC STAR. There is no fallback or degraded
mode. If the platform is unreachable or the SDK version does not match, the agent raises
`PlatformRequired` during graph compile / start-up preflight rather than starting in a partially
working state. This is intentional — a half-running agent is worse than one that refuses to start.

## Quick Start

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
python -m pytest tests/ -v
```

Tests run without a platform connection. Running the agent itself does not.

1. Adjust `config/` for your own environment and policies.
